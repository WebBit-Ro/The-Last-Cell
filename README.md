# Последняя клетка

Логическая детективная игра на русском, украинском и английском языках. Проект работает на чистом HTML, CSS и JavaScript, без сборщика и сторонних библиотек.

## Запуск

1. Распакуй папку проекта.
2. Открой её в редакторе кода.
3. Запусти `index.html` через локальный сервер, например расширение Live Server в VS Code. Это надёжнее, чем открывать файл напрямую: браузеры по-разному ограничивают локальное хранилище для `file://`.

Также можно запустить сервер из папки проекта командой `python -m http.server 8000`, а затем открыть `http://localhost:8000`.

## Структура

- `index.html` — разметка страницы и порядок подключения скриптов.
- `styles.css` — оформление, адаптивная сетка, состояния игры и модальные окна.
- `app.js` — навигация, интерфейс, игровое состояние, подсказки и проверки.
- `levels.js` — данные 442 кампанийных уровней.
- `daily_generator.js` — генератор ежедневных дел.
- `locales/ru.js` — русские тексты, названия объектов и языковые формы.
- `locales/uk.js` — украинские тексты, названия объектов и языковые формы.
- `locales/en.js` — английские тексты, названия объектов и языковые формы.
- `tests/smoke-test.js` — быстрые проверки целостности уровней, локализаций и генератора.

## Интерфейс и доступность

- Финальная палитра — спокойный графитово-синий фон, приглушённый цвет морского стекла для основных действий и тёплые оттенки только для смысловых акцентов.
- Основные кнопки используют тёмный текст на светлом фоне; цветовые состояния согласованы для тёмной и светлой темы.
- Правила представлены обычным нумерованным текстом без декоративной сетки карточек.
- Уменьшены лишние свечения и декоративные тени; добавлена поддержка `prefers-reduced-motion`.
- После завершения последнего дела кнопки закрытия и перехода из решения ведут на главную страницу.

## Проверки

Требуется Node.js. Из корня проекта запусти:

```bash
node tests/smoke-test.js
```

Проверка не требует установки пакетов и не изменяет игровые данные. Она сверяет локализации, структуру 442 уровней, соответствие свидетельств решениям и повторяемость ежедневного дела.

## Прогресс и настройки

Выбранный язык, оформление и прогресс сохраняются в `localStorage` браузера. Чтобы начать с чистого состояния, очисти данные сайта в настройках браузера.
